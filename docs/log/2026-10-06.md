### 2026-10-06 —— 批 52：B6 覆盖率报告 + B8 静态分析（全走约定插件）

- **B6（jacoco，只出报告不设阈值）**：新约定插件 `autoscript.jacoco`（挂 agent，`isIncludeNoLocationClasses` + **`excludes = ["jdk.internal.*"]`** —— 后者必配：JDK 16+ 隐藏 `jdk.internal.*`，instrument 了它们会让测试 worker 起不来，实测三个测试任务同时红在 `NoClassDefFoundError: jdk/internal/reflect/GeneratedSerializationConstructorAccessor1`）+ 两个形态的报告约定（`autoscript.jvm-jacoco` 走 `classes/{kotlin,java}/main`、`autoscript.android-jacoco` 走 `tmp/kotlin-classes/debug` 并排除 R/BuildConfig/Manifest）。由 `autoscript.jvm` / `autoscript.android-library` 内部 apply 覆盖 13 个模块；`:app`（application 形态）单独 apply。**实测 15 个模块出报告**（含两个无源码模块的 NO-SOURCE 空报告）。CI `jvm-tests` job 追加 `./gradlew jacocoTestReport` 与 artifact 路径。
- **B8（detekt，baseline + 新增即红）**：新约定插件 `autoscript.detekt` + 仓级 `build-logic/detekt.yml`（`buildUponDefaultConfig = true`；**重点开** `SwallowedException` / `TooGenericExceptionCaught` —— A7 那一类由规则机械守住；`FunctionNaming` 对 `@Test` 放行以兼容中文反引号测试名）。12 个有源码模块生成 `detekt-baseline.xml` 承载存量（其中 **19 条 `SwallowedException` + 27 条 `TooGenericExceptionCaught` 是 A7 那批「有意降级」的存量**：读系统属性失败回 DEGRADED、幂等清理等 —— 如实留在 baseline 里，**新增即红**）；**实测证伪门有效**：往 `Error.kt` 塞一个吞异常的 `catch (e: Exception)` 后 `:domain:detekt` 当场红（2 条），删除后复绿。CI `jvm-tests` job 追加 `./gradlew detekt`。
- **B8（facade ESLint）**：`bridge/js` 加 flat config + `npm run lint`，规则集**首日即绿**（等价于此后新增违规即红）：关掉 `prefer-const`（本仓有「闭包先引用、随后才赋值」的合法形态 —— `sensors.ts` 的 interval 句柄）、生成物 `src/generated/**` 整体 ignore（另有 `gen:wire` 零 diff 门守着）。CI `js-tests` job 追加 `npm run lint`。

### 2026-10-06 —— 批 49：设置页两组纯文字 + 「权限」改名「权限列表」

- **驱动**：用户四条——「把权限改名为权限列表」；「然后语言切换和帮助文档它们三个设置为同一组」；「它们都不需要图标，还有标题下面的小字，所以去除权限的图标和几项的描述」；「再把反馈 关于 检查更新设置为另外一组」。
- **当场问定两条**（AskUserQuestion）：第一组的三个 = **语言切换、帮助文档、权限列表**（主题切换留在右上 `⋮` 不动）；第二组（反馈 / 关于 / 检查更新）**也不要图标** → 整页纯文字行。
- **逐条落点**：
  1. **改名**：顶页入口与子页顶栏标题「权限」→**「权限列表」**（子页行为不变：九权限同卡、行尾三态值、可授权整行可点）。
  2. **顶页两组纯文字**（`SettingsScreen.kt`）：卡一 = 权限列表（唯一有里页的行）/ 语言切换 / 帮助文档；卡二 = 反馈 / 关于 / 检查更新；两组之间 `SectionGap` **12dp**（TG `ShadowSectionCell` 缺省高 —— 批 44 实测口径；原 `CardGap` 4dp 一并改掉，顺手修掉此前降级卡与权限卡贴死的 0 缝）。未开放的五个入口点击 `LocalToast`「×××尚未开放」（管理面板同款口径）—— **不画空页、不假装有功能**（本仓无 i18n 系统、无帮助文档、无更新检查实现）。
  3. **行组件**（`SettingsCells.kt`）：`SettingsCellRow` 的 `colors`/`glyph` 改**可空**（null = 不画图标块、标题从 18dp 起）；批 48 加的副标题档（`subtitle`/`subtitleTone`/60dp 两行高）**整参数删除** —— 全仓再没有调用方挂「标题下面的小字」（管理面板与权限子页仍带图标：子行是模块自己的脸，用户本批口径指顶页）。
  4. **读态去向**：顶页不再展示读态（原入口副标题位随小字一并撤下）；子页没读到 / 读失败时卡内**如实说一句**（`Status.of` 三态分派照算），不铺空卡。
- **测试**：本批改动全在 Composable 呈现面（`:ui` 无 Robolectric 截图测），既有 102 例照旧覆盖状态层与纯函数；改名文案无测试钉着（与批 44–47 改名同口径）。
- **门**：`:ui:testDebugUnitTest`（102 绿）+ 全模块 `lintDebug` + `:app:assembleDebug`，全绿零跳过；文档链接门 393 条全过。用户指定通过 GitHub Actions 编译交付，设备交互测试由用户完成，本批不使用 ADB。
